# Personagem 1 (Padrão)

Coloque aqui a folha de sprites do seu personagem padrão que irá substituir o personagem de exemplo no timer.

## Arquivo Principal
- Nome: `spritesheet.png`
- Formato: PNG transparente com 3 quadros horizontais:
  - Quadro 1: Posição normal / em pé
  - Quadro 2: Posição de impulso / decolagem
  - Quadro 3: Posição de voo Superman (horizontal)

Ou, alternativamente, coloque 3 imagens separadas:
- `frame1-normal.png`
- `frame2-impulso.png`
- `frame3-voo.png`
